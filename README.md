# fx-50FH calculator simulator

A web simulator of the fx-50FH scientific calculator, built for classroom demos on a projector or smart TV.

**Live site:** https://fx50fh.danfrey.com.hk/ (by Danfrey Education, Danfrey Company Limited, https://www.danfrey.com.hk/). You can also download `index.html` and open it in a browser; it is a single file with no build step.

## Features

- All calculation modes from the user manual: COMP, CMPLX, BASE (DEC/HEX/BIN/OCT, negative numbers in two's complement), SD, REG, and PRGM (program editing and running).
- The 23 built-in formulas (FMLA), scientific constants, and calculation history.
- The mode indicator is always shown on the top row of the display.
- A keystroke log written in the manual's notation.
- Projection aids: zoom, full screen, a large pointer that shows each key press, and an option to hide tips.
- BASE binary width can be set to 10 bits (as on the real calculator), 16 bits or 32 bits.
- Keyboard shortcuts for digits and operators.

## Notes

- The manual has no full picture of the keyboard, so the key layout was worked out from the key labels in its examples. It may differ slightly from the real calculator.
- This is an independent teaching tool and is not affiliated with the calculator's maker.
